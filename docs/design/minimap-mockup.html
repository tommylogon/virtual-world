Open questions this mockup is meant to settle. 1. One cell is not one area. Cell (10,3) holds both Deep Forest and Sparse Forest (Eldenford interior 10,3); road areas share cells with forest. The minimap's unit has to be the cell, with a stacked badge — a hover lists every area in it. 2. Fog reads as empty, and empty reads as "there is nothing there". The fog toggle compares omitting the extent against hatching it. 3. Names embed their own coordinates — "Road (Eldenford interior 13,5)". On a grid that is redundant in a tooltip and long in a cell. 4. Portrait size. Same data at 22px and 34px, below. The 18px chip in turn-scene-view.ts:459 already ships; this is a prominence question, not a missing feature. 5. "You are here" is not entry_cell. A scope's entry_cell is where a scoped load drops a character (world is (4,1), eldenford_interior is (13,2)); the blue ring is this character's position, which is player.current_area resolved to a cell. Conflating them puts the marker in the wrong place on every scope load. 6. A way marker must straddle the boundary, not sit in a cell. First pass drew the ✖ inside the lower of the two cells and it swallowed that cell's hover — the way tooltip came up instead of the room's. Ways carry a half-integer coordinate (world_compile.py:2055), so the marker belongs on the grid line and its hit box has to be small enough that neither cell loses the hover.
