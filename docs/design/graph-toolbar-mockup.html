Graph workspace — UX redesign

Mockup / spec only — no app changes. Prototype is interactive: switch states, open View, pick a layout, select a scope.

1 · Why regrouping the strip isn't a redesign

The current bar is one row of ~29 peer controls. Regrouping changes spacing; it doesn't change the model. Four unrelated mental models share one plane:

🏠 Area📦 Item🚪 Way📚 Library📦 Structures🗺️ WorldPainter ↩️↪️📜 🔮 Graph🗺️ Map📊 Overlays ▾ ⏸ Physics🌳 Levels⊞ Fit📷 PNG 🔍 SearchKEEP🌍 Whole world 🏘 Inhabited🖼 Images🔩 Triggers📦 Items🏢 Floors 🏷 Labels⋯ More ▾📋 Copy Prompt📝 Paste Response
  • Do (build, undo) · Where (scope) · Look (layout, overlays, visibility) · Session (copy/paste prompt) — all at equal visual weight.
  • State lives in button labels, not in the UI: Map renames itself “Graph”, Overlays renames itself “💡 Light”, Levels has no on/off at all.
  • Scope — the single most important control on a painted world — is a plain dropdown in the middle. Nothing shows what's loaded, from which scope, or how big it is.
  • Ineffective controls are always enabled: KEEP does nothing with no query, Paste Response fails unless Manual Mode is on.
  • Hick's law: 29 roughly-equal targets ≈ slow scanning. A good bar shows ≈7.

2 · Proposed information architecture

Two tiers. A thin primary bar with 4 zones, and a contextual scope bar that appears only when a world scope is loaded. Everything rare moves behind View ▾ / ⋯ More ▾ / the command palette.

Do — actions

  • ➕ Build ▾ — Area · Item · Way · Library · Structures · WorldPainter
  • Undo · Redo · History (grouped, icon-only)

Where — context & data

  • Scope chip — opens the scope tree; shows the active zone
  • Scope bar — breadcrumb, loaded-node count, Generate / WorldPainter / Clear
  • Search + Keep layout (disabled until a query exists)

Look — presentation

  • Layout — segmented Graph · Map · Levels (one truth, no renaming)
  • View ▾ — Overlays (None default), Legend, Show…, Edge labels
  • Fit · Physics (disabled when Levels/an overlay owns positions)
  • ⋯ More ▾ + command palette for the rest

4 · Rationale — principle → decision → effect

PrincipleDecisionEffect
Separate mental modelsDo / Where / Look zones; Session actions leave the graph barYou scan 7 targets, not 29
Progressive disclosureRare config behind View ▾ and More ▾ (plus ⌘K palette)Default bar stays stable; power features one click deeper
State, not labelsLayout is a segmented control with aria-selected; Physics greys out when it can't runNo self-renaming; you can see which mode is on
Context over configurationA scope bar appears when a zone is loaded, with breadcrumb + node count + GenerateThe painted-world workflow gets first-class UI
Recognition over recallIcons paired with words on primary controls; labels on every View chipNo guessing what “KEEP” or “🔩” means
Honest affordancesDisable KEEP with no query; disable Paste unless Manual Mode is on; disable Physics under LevelsNo silent no-ops
Accessibilityrole=tablist/aria-selected, aria-expanded, visible focus, titles as descriptionsKeyboard and screen-reader usable
ResponsiveDo and Look zones collapse into overflow before Where doesScope + search survive narrow widths

Behaviour bugs carried into the design

  • Legend: overlays update it in place; never auto-opens; explicit toggle + ✕.
  • Layout: Graph / Map / Levels mutually exclusive; fixed labels.
  • Overlays: explicit None; cardinal removed from the overlay list (it's a layout).
  • Prompt actions: moved out of the graph bar to the agent/session area (Copy is a 3rd duplicate today).
  • KEEP: renamed “Keep layout”, disabled until a search exists.
