- `decision_flow.html` / `decision_flow.png` - Final Sammy Lopez turn sequence diagram (`sequenceDiagram`: World + Factual Lane -> Body/Identity/Rel -> Cue + Recall -> Intermediator -> Active Mind + MOSIAC -> Actor + Social Mask -> Interpreter + Dynamics).
